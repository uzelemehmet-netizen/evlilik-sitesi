## Başvuru alanlarına önerilen eşleştirme

Google formunda alan isimleri farklı olabilir; tipik eşleştirme:

- **Privacy Policy URL** → https://uniqah.com/privacy
- **Terms of Service / User Agreement URL** → https://uniqah.com/docs/matchmaking-kullanim-sozlesmesi.html
- **Community Guidelines / Rules URL** → https://uniqah.com/docs/site-kurallari.html
- **Data Processing / Privacy Notice (KVKK/GDPR) URL** → https://uniqah.com/docs/kvkk-aydinlatma-metni.html
- (Opsiyonel) **Refund / Cancellation Policy URL** → https://uniqah.com/docs/iptal-iade-politikasi.html
- (Opsiyonel) **All legal docs page** → https://uniqah.com/documents

Ürün/app linkleri istenirse:

- **Product / App Home** → https://uniqah.com/
- **Matchmaking / Core feature page** → https://uniqah.com/eslestirme
- (Varsa) **Service page** → https://uniqah.com/wedding
- (Login) **User dashboard / profile** → https://uniqah.com/profilim

## Notlar

- `/privacy` bir React route’dur; diğerleri `/public/docs` altındaki statik HTML dokümanlarıdır.
- Başvuru ekranında kullanıcı onay metninde KVKK bağlantısı da gösterilir.
